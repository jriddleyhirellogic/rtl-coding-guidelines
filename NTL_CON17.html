NTL_CON17

Message: Do not connect tie off cell to logic 0 /logic 1

Description This rule verifies that tie-off cells are not connected to supply. Tie-off cells provide the connection to supply, so they must not be connected themselves to supply. Tie-off cells are special cells in a physical library.This rule only detects direct connections to supply (1'b0 or 1'b1) or connections to nets detected as supplies using the supply1 or supply0 constructs. If the supply connection is implemented through a tie-off cell, this rule does not fire. You can use the rule_set_parameter Tcl command and the TIE_OFF_CELLS parameter to specify tie-off cells for this rule. For example:
leda> rule_set_parameter -rule NTL_CON17 \
-parameter TIE_OFF_CELLS -value {TIE1, TIE2}
Note that the TIE_OFF_CELLS parameter that you can configure with this rule also affects NTL_CON06, NTL_CON10, and NTL_CON16.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con17_top ();
supply0 GND;
supply1 VDD;

tohlsx1 U1 (.TH(VDD)); // tie off cell in a physical library 
tohlx1 U2 (.TH(VDD)); // tie off cell in a physical library 
tohsx1 U3 (.TH(VDD)); // tie off cell in a physical library 
tohx1 U4 (.TH(VDD)); // tie off cell in a physical library
tolsx1 U5 (.TL(GND)); // tie off cell in a physical library
tolx1 U6 (.TL(GND)); // tie off cell in physical library
endmodule
