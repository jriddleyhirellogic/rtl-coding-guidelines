NTL_STR70

Message: Set and reset signals must not come from a common source

Description This rule fires when Leda detects set and reset signals coming from a common source in the design. This can result in data failures caused by competition and contradiction.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str70_top ;
...
// GTECH_FD3 - flip-flop with reset (CD) and set (SD)
GTECH_FD3 I0(.D(Din), .CP(Clock), .CD(Ctrl), .SD(Ctrl), .Q(Dout)); 
// NTL_STR70 fires -- Set and Reset signals come from a common source
endmodule
