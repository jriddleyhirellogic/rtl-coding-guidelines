NTL_CLK49

Message: Clock signal gated with a XOR gate %s.
Description Leda flags this rule when there is a XOR gate in the clock path, and thus a gated clock is generated in the design. Arguments%s: the hierarchy name of the gate output.
Policy Design
Ruleset Clock
Language Verilog/VHDL
Type Netlist
Severity Error

Example:

The following example illustrates the rule: 

module top(Y1,Y2,Y3,D1,D2,D3,T,EN,T2,EN2,EN3);
 input D1,D2,D3,T,EN,T2,EN2,EN3;
 output Y1,Y2,Y3;

 DFF I1(.Q(Y1), .DATA(D1), .CLK(T));
 DFF I2(.Q(Y2), .DATA(D2), .CLK(I5_Y));

 XOR2 I5(.Y(I5_Y),.A(EN2),.B(T));

endmodule
Configuration:
 
rule_deselect -all
rule_select -rule NTL_CLK49
Violations:
 
    8:  XOR2 I5(.Y(I5_Y),.A(EN2),.B(T));
         ^
doc.v:8: CLOCKS> [ERROR] NTL_CLK49: Clock signal gated with a XOR gate 
top.I5.~bxor0

   ---  Enable input signal is: top.I5.A (file: doc.v, line: 8)
