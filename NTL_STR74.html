NTL_STR74

Message: A non-tristate net shall have zero bus keeper

Description This rule verifies that no bus keepers are connected to non-tristate nets. Connecting a bus keeper to a non-tristate net is useless.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str74_top ();
wire Enable, net_01, net_02, net_03;

assign net_03 = Enable & net_01 & net_02;

//BK1x0 - bus keeper cell (bus holder)
BK1x0 I1(.A(net_03)); 
// NTL_STR74 fires -- bus keeper to non-tristate net  
...
endmodule
