NTL_DFT28

Message: Scan clock should be called scan_clk...

Description This rule fires when Leda detects a scan clock that is not named scan_clk for easy identification.
Policy DESIGN
Ruleset DFT
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

...
// Scan DFF -- SDFF
SDFF U0(.D(Din), .CP(Clock), .TI(Scan_in), .TE(Scan_en), .Q(Dout_temp)); 
// NTL_DFT28 fires -- scan clock is called Clock in scan chain1
SDFF U1(.D(Din), .CP(scan_clk), .TI(Dout_temp), .TE(Scan_en), .Q(Dout));                  
// OK -- scan clock is called scan_clk in scan chain2
...
