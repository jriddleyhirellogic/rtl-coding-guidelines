NTL_SET04

Message: Locally gated asynchronous sets should be avoided %s

Description This rule flags when Leda detects locally gated asynchronous sets in the design. You can avoid sequence errors caused by gate logic competition by removing locally gated asynchronous sets from your design.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module top (rst, ren, clk, data, q);

input rst, ren, clk, data;
output q;
reg q;
wire grst;

assign grst = rst | ren; // NTL_SET04 flags - gated async. set found

always @(posedge clk or posedge grst)
begin
  if (grst == 1)
    q <= 1;
  else
    q <= data;
end

endmodule
