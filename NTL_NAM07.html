NTL_NAM07

Message: A registered output port should end with _r

Description This rule fires when Leda detects a registered output port name that does not end with _r. This naming style makes the design more explicit and readable.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_nam07_top(Clock, Reset, Din1, Din2, Dout1, Dout2_r);
...
output Dout1; 
// NTL_NAM07 fires -- the name of this registered ouput port
// does not end with _r 
output Dout2_r; 
// OK -- The name of this registered ouput port ends with _r 
...

GTECH_FD2  U0 (.D(Din1), .CP(Clock), .CD(Reset), .Q(Dout1), .QN() );  
GTECH_FD2  U1 (.D(Din2), .CP(Clock), .CD(Reset), .Q(Dout2_r), .QN() );  
endmodule
