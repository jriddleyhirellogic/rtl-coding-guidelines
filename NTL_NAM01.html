NTL_NAM01

Message: Use the same name for all clocks that are driven from the same source

Description This rule fires when the name of clock signal from the same source is changed when it passes through a hierarchy module or renamed by assign statement.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module Name01_top(); ...
assign clk_1 = clk; // fired because clock is assigned to another name
always @(posedge clk)
   din_temp1 <= din;

always @(posedge clk_1)
   din_temp2 <= din;

name01_sub1 U1(.clk(clk_sub), .din(din_temp1), .dout(din_temp2));
// fired
endmodule

module name01_sub1(clk, din, dout);  ...
always @(posedge clk)
   dout <= din;

endmodule

This is an example of a valid Verilog code 

module Name01_top();
input clk; //clock signal
...
always @(posedge clk)
   din_temp1 <= din;

name01_sub1 U1(.clk(clk), .din(din_temp1), .dout(din_temp2)); // fired
endmodule

module name01_sub1(clk, din, dout);
...
always @(posedge clk)
   dout <= din;
endmodule
