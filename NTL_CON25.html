NTL_CON25

Message: Number of pin-pairs in design.
Description LEDA flags this rule when it detects pin-pairs in the design. Two pins connected by one signal are considered to be a pin-pair. You may need this information to check or estimate a design attribute.You can use the following parameter to print a secondary message for this rule:NEED_DETAIL_INFO: This parameter prints the secondary message.The default value of the parameter is 0. The secondary message is printed when the parameter value is 1.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Warning
