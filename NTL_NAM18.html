NTL_NAM18

Message: A signal fed through an inverter or buffer may only have its suffix changed

Description This rule fires when Leda detects that a signal fed through an inverter or buffer has only its suffix changed (for example, for inverter with suffix _n or _N, or for buffer with suffix _b or _B). This can ease traces on such signals in tests.You can configure this rule using the rule_set_parameter Tcl command and the USER_INV_NAME parameter to specify the inverters to check and the USER_BUF_NAME parameter to specify the buffers to check. The default inverter is GTECH_NOT and the default buffer is GTECH_BUF. For example:
leda> rule_set_parameter -rule NTL_NAM18 \
-parameter USER_INV_NAME -value {_inv}

Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_nam18_top(Clock, Reset,  Din, Dout);
input  Clock, Reset, Din;
output Dout;
reg Dout;

wire Clock_n, Clock_n_buf, Clock_n_buf_n; 
//signals feed through inv or buf

GTECH_NOT U0(.A(Clock), .Z(Clock_n)); //signal through inv with _n
GTECH_BUF U1(.A(Clock_n), .Z(Clock_n_buf)); 
// NTL_NAM18 fires -- signal through buf without _buf 
GTECH_NOT U2(.A(Clock_n_buf), .Z(Clock_n_buf_n));
// OK -- Signal through inv with _n 
GTECH_FD2  U3(.D(Din), .CP(Clock_n_buf_n), .CD(Reset), .Q(Dout));
endmodule
