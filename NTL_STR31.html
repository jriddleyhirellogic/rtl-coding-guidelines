NTL_STR31

Message: Netlist not uniquified

Description This rule fires when more than one instance of the same module is found in the design.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

Here are examples of valid and invalid Verilog code that illustrates the problem and the solution: 

// Invalid example
module ntl_str31_top ;
...
//Same_sub_block - a sub-module
Same_sub_block I1(.Clock(CLock), .Reset(Reset), .Din(Din), 
.Dout(Dout_int));
Same_sub_block I2(.Clock(CLock), .Reset(Reset), .Din(Dout_int), 
.Dout(Dout));
// NTL_STR31 fires -- instance Same_sub_block is not uniquified 
endmodule

// Valid example
module ntl_str31_top ;
...
//Same_sub_block_1/ Same_sub_block_2  - a sub-module
Same_sub_block_1 I1(.Clock(CLock), .Reset(Reset), .Din(Din), 
.Dout(Dout_int));
Same_sub_block_2 I2(.Clock(CLock), .Reset(Reset), .Din(Dout_int), 
.Dout(Dout));
// OK -- instance Same_sub_block_1/Same_sub_block _2 is uniquified 
endmodule
