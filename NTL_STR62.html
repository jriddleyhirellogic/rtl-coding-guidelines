NTL_STR62

Message: Netlist shall not have parallel drive situations

Description This rule fires when Leda detects nets that have more than one driver instantiated in the same module in the design. Connecting cells in parallel must be done carefully and only used when needed (for example, when driving a highly loaded net). You can activate this rule to double check such nets. Make sure the nets are stable and that there are no data failures or problems with load strength.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str62_top;
...
buf I1(Din_par, Din);
buf I2(Din_par, Din); 
// NTL_STR62 fires -- Din_par signal has parallel drive situation
...
endmodule
