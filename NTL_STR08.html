NTL_STR08

Message: The number of gate instantiation should not exceed <NB_MAX_GATES> in instance: %s1

Description This rule fires when Leda detects a number of gate instantiations in a module that exceeds the number specified by the user. Sometimes, the number of gate instantiations is limited to a number that improves the quality of synthesis and timing analysis. You can configure this rule for the maximum number of gate instantiations using the rule_set_parameter Tcl command and the NB_MAX_GATES parameter. The default value is 10. For example:
leda> rule_set_parameter -rule NTL_STR08 \
-parameter NB_MAX_GATES -value {15}
Arguments:
    • %s1 is the hierarchy name of the instance.
The position is the line where the instance is used.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str08_top;
...
// a gate instantiation
Gate_inst I0 (.In(net_00), .Out(net_10);   
Gate_inst I1 (.In(net_01), .Out(net_11);
...
Gate_inst I10 (.In(net_0a), .Out(net_1a); 
// NTL_STR08 fires -- the number of Gate_inst > 10 (10 is the default)
...
endmodule

Secondary Message

The number of instantiated gates in the instance is %d1: %s2.

The instantiated gate: %s3.

Argument

%d1 is the total number of instantiated gates in the instance.

%s2 is the hierarchy name of the instance.

%s3 is the hierarchy name of the detected gate.
