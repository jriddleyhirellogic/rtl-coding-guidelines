NTL_RST10

Message: Reset signal gated with an AND gate

Description This rule fires when Leda detects an AND gate on a reset path. This generates a gated reset that can cause sequence problems and logic gate competition.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_rst10_top;
...
wire Reset_AND;
assign Reset_AND = Reset & Ctrl; 
// NTL_RST10 fires -- AND gated reset signal

always @(posedge Clock)
begin
   if (!Reset_AND)
        Dout <= 0;
   else Dout <= Din;
end
endmodule
