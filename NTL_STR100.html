NTL_STR100

Message: When area size of hierarchy is more that 10000, it should not have glue logics

Description Limit the gate size of a single level to 10,000 gates or fewer to ensure safety. As the operating frequency becomes higher, keep the size of a single level as small as possible. Limit the gate size of a level to 20,000 gates or fewer even when the operating frequency is low (mandatory). You can use the rule_set_parameter Tcl command to configure the MAX_AREA_SIZE and AREA_LIB parameter. The default value of MAX_AREA_SIZE is 10000 and the default value of . AREA_LIB is vcorelib.For example:
leda> rule_set_parameter -rule NTL_STR100 -parameter 
MAX_AREA_SIZE -value {20000}
leda> rule_set_parameter -rule NTL_STR100 -parameter 
AREA_LIB -value ...
If you want to change the DB library from vcorelib (default) to lsi_10k, you need to set $search_path and $link_library too.For example:
setenv search_path "<path to the lsi_10k.db>"
setenv link_library "lsi_10k.db"
leda> rule_set_parameter -rule NTL_STR100 -parameter 
AREA_LIB -value {lsi_10k}
