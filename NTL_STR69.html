NTL_STR69

Message: Do not use feedthrough

Description This rule fires when Leda detects output nets fed by input nets through instances without any other components. Removing such nets from your design improves synthesis performance and design partitioning.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str69_top (Din, Dout);
input Din;
output Dout;

assign Dout = Din; 
// NTL_STR69 fires -- Dout is connected to Din directly 
//assign Dout = ~Din; // is OK
endmodule
