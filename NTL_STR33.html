NTL_STR33

Message: Asynchronous feedback loop detected

Description Asynchronous feedback loop detected. Avoid using feedback in combinational circuits.You can configure this rule using the rule_set_parameter Tcl command to set the STOP_ON_LATCH parameter to flag or not, if there is a latch on the asynchronous feedback loop path. The default value is 0. By default, if there is a latch on the asynchronous feedback loop path, this rule flags. If you do not want this rule to flag when there is a latch on the asynchronous feedback loop path, then you need to configure the parameter STOP_ON_LATCH as follows:
leda> rule_set_parameter -rule NTL_STR33 \
-parameter STOP_ON_LATCH -value {1}
You can set the parameter TRACE_FROM_SIGNAL to 1, that configures the rule to check on the internal signals. For example:
leda> rule_set_parameter -rule NTL_STR33 \
-parameter TRACE_FROM_SIGNAL -value {1}
The default value is 0. By default, this rule checks only the ports of instances.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This following example illustrates the problem: 

module LATCH (input I, input C, output reg O);
  always @*
	if (C)
	O <= I; // NTL_STR33 flags here
endmodule
 
module top (input I, input C, output reg O);
wire tmp;
wire tmp2;
	LATCH latch1(.I(tmp2), .C(C), .O(tmp));
	LATCH latch2(.I(tmp), .C(C), .O(tmp2));

endmodule
