NTL_RST19

Message: Use only one edge of the reset

Description This rule fires when Leda detects a reset signal that is used on more than one edge of the clock.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_rst19_top;
input Clock, Reset;
...
wire net_11, net_21;
reg   net_12, net_22;
...
always @(posedge Clock or posedge Reset)
// OK -- one edge of the reset with posedge  
begin
   if (Reset)
        net_12 <= 0;
    else  net_12<= net_11;
end

always @(posedge Clock or negedge Reset) 
// NTL_RST19 fires -- another edge of the reset with negedge 
begin
   if (!Reset)
        net_22 <= 0;
    else  net_22<= net_21;
end
endmodule
