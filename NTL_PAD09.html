NTL_PAD09

Message: Forbidden PAD connection

Description This rule fires when Leda detects nets connected to PAD pins of cells (named PAD or DQ) in the design, and returns a list of such nets. You can configure this rule using the rule_set_parameter Tcl command and the SUPPLY_LIST parameter to specify the power signals that cannot be connected to PADs. The default power signal names for this rule are VSS and VDD. For example:
leda> rule_set_parameter -rule NTL_PAD09 \
-parameter SUPPLY_LIST -value {POWER_P}

Policy DESIGN
Ruleset PAD
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_pad09_top;
.. 
supply1 VDD; //VDD is an signal in the 'supply _list'(user provided)
supply0 VSS;  //VSS is an signal in the 'supply_list' (user provide)

// signal named with '_pad' is an input/output of top-level
Design _core U0(.Ctrl(Ctrl), .Din(Din), .Dout(Dout));

// PAD cells: PGI_ECS277Ex - input PAD cell; PGO_CDPA77Ex 
// output PAD cell
PGI_ECS277Ex  U1( .PULL(VSS), .ENABQ(VSS), .PULLQ(VDD),
                        .PAD(VDD), .OUTI(Ctrl));  
// NTL_PAD09 fires -- VDD is in supply_list (user provided). It is a
// violation when a signal listed in supply_list is connected to PAD pin 
// of IOLIB cells

PGI_ECS277Ex  U2( .PULL(VSS), .ENABQ(VSS), .PULLQ(VDD), 
.PAD(Din_pad), .OUTI(Din)); // OK

PGO_CDPA77Ex  U3( .PULL(VSS), .PP_EN(VDD), .ENQ(VDD), .PULLQ(VDD), 
.PAD(Dout_pad), .DQ(VSS));  
// NTL_PAD09 fires -- VSS is in supply_list (user provided). It is a
// violation when a signal listed in supply_list is connected to the 
// DQ pin of IOLIB cells
 
endmodule
