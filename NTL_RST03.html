NTL_RST03

Message: All registers must be asynchronously set or reset %s1

Description This rule fires when Leda detects a register in the design that is not asynchronously set or reset. Here, a flip-flop is taken as a register. You can activate this rule for checking in special cases such as design for test (DFT).Arguments:
    • %s1 is the non-asynchronous flip-flop
The position is the line in which the non-asynchronous flip-flop is instantiated.The secondary message of this rule is "Other instance %s2".Arguments:
    • %s2 is another non-asynchronous flip-flop which is instanced the same instance %s1.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of valid Verilog code that illustrates the correct approach: 

module ntl_rst03_top;
...
always @(posedge Clock or posedge Reset_asyn)
// OK -- asynchronously reset
begin
   if (Reset_asyn)
           Dout <= 0;
   else  Dout <= Din;
end
endmodule
