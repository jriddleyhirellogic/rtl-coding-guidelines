NTL_SET03

Message: Don't use one set signal for both asynchronous set and synchronous set %s

Description This rule flags when Leda detects a set signal that is used both as an asynchronous set and a synchronous set in the design. Such signals are dangerous in sequential designs because they can cause sequence errors and data failures. Using set signals as only synchronous or asynchronous (not both) also improves set tree analysis.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module top (clk1, clk2, din1, din2, set, dout1, dout2);

input clk1, clk2, din1, din2, set;
output dout1, dout2;
reg dout1, dout2;

always @(posedge clk1 or posedge set)
begin
  if(set == 1)
    dout1 <= 1;
  else
    dout1 <= din1;

end

always @(posedge clk2)
begin
  if(set == 1) // NTL_SET03 fires - signal set used as synchronous set
    dout2 <= 1;
  else
    dout2 <= din2;
end

endmodule
