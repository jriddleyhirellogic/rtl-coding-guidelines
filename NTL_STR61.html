NTL_STR61

Message: Do not use clock or enable signals as data inputs

Description This rule fires when Leda detects clock and enable signals used as data inputs. Using control signals as data in the design can cause sequence errors and data failures.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str61_top ;
...
wire enable_int;
assign net_02 = enable_int ? Din :1'bz; //enable signal
//DFF - flip-flop cell
DFF I0(.D(enable_int), .CP(Clock), .Q(net_02)); 
// NTL_STR61 fires -- enable signal as data input
DFF I1(.D(Clock), .CP(Clock), .Q(net_03)); 
// NTL_STR61 fires -- clock signal as data input
endmodule
