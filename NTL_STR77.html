NTL_STR77

Message: Prohibit Cell

Description This rule fires when Leda detects prohibited cells in the design. You can use the rule_set_parameter Tcl command and the PROHIBITED_CELLS parameter to configure the list of prohibited cells. The default value is FD1P FD2P. For example:
leda> rule_set_parameter -rule NTL_STR77 \
-parameter PROHIBITED_CELLS -value {CELL1, CELL2, 
CELL3}
Wild cards can also be used to specify the parameter values. For example, -value {[A-I]CELL? CELL* *CELL}By default, this rule will report only once even if the prohibited cell is instantiated multiple times. To enable reporting violation for each prohibited cell instantiation, the following parameter should be set as follows:
leda> rule_set_parameter -rule NTL_STR77 \
-parameter MSG_ON_EACH_INSTANCE -value {1}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

endmodule
