NTL_CON06

Message: Input pin tied to supply

Description This rule verifies that no input pins of instances are connected to a supply. Input pins may be tied to supply via manual modification of the netlist or a non-optimized cell (can be linked to a don't touch abuse). Such problems are usually solved after reoptimization.By default, this rule checks leaf cells only (ignores hierarchical modules). If you want this rule to check all hierarchical modules, set the ONLY_APPLY_ON_LEAF_CELL parameter to 0 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON06 \
-parameter ONLY_APPLY_ON_LEAF_CELL -value {0}
This rule only detects direct connections to supply (1'b0 or 1'b1) or connections to nets detected as supplies using the suplly1 or supply0 constructs. If the supply connection is implemented through a tie-off cell, this rule does not fire. You can use the rule_set_parameter Tcl command and the TIE_OFF_CELLS parameter to specify tie-off cells for this rule. This parameter is specified along with rule NTL_CON17, so you must specify the tie-off cells as follows:
leda> rule_set_parameter -rule NTL_CON17 \
-parameter TIE_OFF_CELLS -value {TIE1, TIE2}
Note that the setting for TIE_OFF_CELLS also affects the behavior of NTL_10, NTL_CON16, and NTL_CON17.By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_INPUTS to 1, to apply this check only on input ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON06 \
-parameter APPLY_ONLY_ON_INPUTS -value {1}
If an inout port is derived with the "PAD" attribute from a DB cell, or if the inout port is owned by an analog DB cell (with the attribute "is_analog") yet the inout port is not a digital pin (without the attribute "is_digital_pin"), such an inout port will not be taken as an input to be checked by this rule even if the parameter APPLY_ONLY_ON_INPUTS is set to 0. Connection of such inout ports to supply is considered to be fine.

Example

Here are examples of invalid Verilog code that illustrate the problem. In the first example, the ONLY_APPLY_ON_LEAF_CELL parameter is left at the default value of 1. In the second example, the ONLY_APPLY_ON_LEAF_CELL is set to 0: 

// ONLY_APPLY_ON_LEAF_CELL = 1
module ntl_con06_top (Clock, Reset, Din1, Din2, Dout1, Dout2);
input Clock, Reset, Din1, Din2;
output Dout1, Dout2;
supply1 Din1; // NTL_CON06 fires -- input pin tied to supply
supply0 Din2; // NTL_CON06 fires -- input pin tied to supply
...
GTECH_FD1 I1 (.D(Din1), .CP(Clock), .Q(Dout1) ); 
GTECH_FD2 I2 (.D(Din2), .CP(Clock), .CD(Reset),.Q(Dout2) );   
// NTL_CON06 firez -- input pin of GTECH_FD* (LEAF_CELLs) tied to supply
...
endmodule

// ONLY_APPLY_ON_LEAF_CELL = 0
module ntl_con06_top (Clock, Reset, Din1, Din2, Dout1, Dout2);
input Clock, Reset, Din1, Din2;
output Dout1, Dout2;
reg Dout1, Dout2;
supply1 Din1; // NTL_CON06 fires -- input pin tied to supply
supply0 Din2; // NTL_CON06 fires -- input pin tied to supply
...
ntl_con06_sub U1 (.Clock(Clock),.Reset(Reset),.Din(Din1),.Dout(Dout1) );
ntl_con06_sub U2 (.Clock(Clock),.Reset(Reset),.Din(Din2),.Dout(Dout2) );
...
endmodule

module ntl_con06_sub (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
...
endmodule
