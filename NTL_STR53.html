NTL_STR53

Message: Anti-skew latch enable not controlled by main clock

Description This rule fires when Leda detects anti-skew latch enables that are not controlled by the main clock. An anti-skew latch is one that is used to save data at the crossing of two clock domains. When latches are used as anti-skew elements, their enable signals should be controlled by the main clock of the circuit. They should be transparent on the inactive state of this clock. In any other case, if a transparent latch is absolutely needed, its enable signal should be accessible in test mode.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

Here are examples of valid and invalid Verilog code that illustrate the problem and the solution: 

// Invalid example
module ntl_str53_top ;
input Clock_sys, Clock_2; 
//Clock_sys is a main clock, Clock_2 is a clock
...
wire net_01; // an internal signal 
GTECH_FD2S I1(.D(Din), .CP(Clock_sys), .CD(Reset), 
.TI(test_in), .TE(test_enable), .Q(Dout_int1));

GTECH_LD1   I2(.D(Dout_int1), .G(net_01), .Q(Dout_int2));     
// NTL_STR53 fires -- latch enable not controlled by main clock 
GTECH_FD2S I3(.D(Dout_int2), .CP(Clock_2), .CD(Reset), 
.TI(Dout_int2), .TE(test_enable), .Q(Dout));
...
endmodule

// Valid example
module ntl_str53_top ;
...
GTECH_FD2S I1(.D(Din), .CP(Clock_sys), .CD(Reset), 
.TI(test_in), .TE(test_enable), .Q(Dout_int1));
GTECH_LD1  I2(.D(Dout_int1), .G(Clock_sys), .Q(Dout_int2));  
// OK -- latch enable is controlled by main clock Clock_sys, data will
// pass transparently in the contrary state of clocking data
GTECH_FD2S I3(.D(Dout_int2), .CP(Clock_2), .CD(Reset), 
.TI(Dout_int2), .TE(test_enable), .Q(Dout));
endmodule
