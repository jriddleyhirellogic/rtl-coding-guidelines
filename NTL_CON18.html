NTL_CON18

Message: There is output port, but it is not connected internally %s1

Description This rule fires when Leda detects an output port that is not connected internally in an instance. You can activate this rule to double check such ports and avoid data failures.Arguments:
    • %s1 is the hierarchy name of the output port in the instance in which the port is not connected internally.
The source position of this rule is the line in which the output port is defined.The secondary message of this rule is "Output port connectivity path: %s2".Arguments:
    • %s2 is the hierarchy name of the other tied output port.

Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con18_top (Reset, Din, Dout1, Dout2);
input Reset, Din;
output Dout1;      
output Dout2; // NTL_CON18 fires -- output, but not connected internally 

assign Dout1 = !Reset ? 0 :  ~Din;
endmodule
