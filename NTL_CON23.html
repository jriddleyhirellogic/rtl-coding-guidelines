NTL_CON23

Message: Incorrect connection: Module output is connected to input of its sub-module

Description This rule fires when Leda detects a module output connected to the input of one of its own submodules.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con23_top(Din1, Din2, Dout1, Dout2);
input   Din1, Din2;
output Dout1, Dout2;
...
Design_core U0 (.Din1(Din1), .Din2(Dout_2), .Dout(Dout1));  
// NTL_CON23 fires -- output is connected to input of its submodule
...
endmodule

module Design_core(Din1, Din2, Dout);
input Din1, Din2;
ouput Dout;
...
endmodule
