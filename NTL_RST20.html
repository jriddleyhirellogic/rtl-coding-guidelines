NTL_RST20

Message: All latches must be asynchronously set or reset: %s

Description This rule fires when Leda detects latches that are not asynchronously set or reset.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

`timescale 1ns/1ps
module ntl_rst20 (Y1, Y2, A, G, RST, SET);
output Y1, Y2;
input A, G, RST, SET;

TB2DLATLQXL  LAT1 (.DATA(A), .GTB(G), .Q(Y1)); // NTL_RST19 fires

TB2DLATQRBXC LAT2 (.DATA(A), .GT(G), .Q(Y2), .RB(RST) ); // PASS

TB2DLATQSBXA LAT3 (.DATA(A), .GT(G), .Q(Y2), .SB(SET) ); // PASS

endmodule
