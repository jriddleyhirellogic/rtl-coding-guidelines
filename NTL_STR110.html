NTL_STR110

Message: A signal without a resolution function cannot have multiple sources driving it

Description This rule checks for signals not having a resolution function but driven by multiple sources.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL
Type Hardware
Severity Warning

Example

entity full_adder is port (

A, b, c: in bit;

Sum,c_out: out bit) end full_adder;

architecture full_adder_arch of full_adder is

Signal s1: bit; // Signal driven by multiple sources, doesn't have a
              // resolution function.

begin

S1 <= A;

S1 <= B;

S1 <= C_in;

end full_adder_arch
