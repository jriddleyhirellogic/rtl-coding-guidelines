NTL_RST05

Message: Don't use asynchronous set/reset signal except for initial reset

Description This rule fires when Leda detects external set/reset is synchronous or internal generated set/reset signal is asynchronous. Using external asynchronous set/reset can quickly and easily set/reset the flip-flops. Using internal generated synchronous set/reset signals can synchronize the data and decrease data failures and it will cause clock and set/reset skew.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is a Verilog code that illustrates the problem: 

module rst05(Clk, Rst1, Rst2,Din);
input Clk, Rst1,Rst2, Din;
reg Rst_int1,Rst_int2,Temp1,Temp2,Temp3,Temp4;
always @(posedge Clk or posedge Rst1) begin
     if (!Rst1)
            Rst_int1 <= 0;
     else Rst_int1 <= 1;     // Rst_int1 - internal generated reset 
end
always @(posedge Clk) begin
     if (!Rst2)
            Rst_int2 <= 0;
     else Rst_int2 <= 1;    // Rst_int2 - internal generated reset 
end
always @(posedge Clk or posedge Rst1)  begin
      if (Rst1)             // OK - initial reset signal is asynchronous
             Temp1 <= 0;
      else Temp1 <= Din;
end
always @(posedge Clk)  begin
      if (Rst2)           // NTLRST05 fires -- initial reset signal
             Temp2 <= 0;
      else Temp2 <= Din;
end
always @(posedge Clk)   begin
      if (Rst_int1)  // OK -- internal reset signal is synchronous
            Temp3 <= 0;
      else Temp3 <= Din;
end
always @(posedge Clk or posedge Rst_int2)   begin
      if (Rst_int2) // NTLRST05 fires -- initial reset signal is async.
           Temp4  <= 0;
      else  Temp4 <= Din;
end
endmodule
