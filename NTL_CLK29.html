NTL_CLK29

Message: Primary input feeds multiple clock domains

Description When you run this rule, Leda infers information about reset and primary input signals in a PI_RESET_CLOCK_MAP.tcl file in the current working directory. You can modify this file so that subsequent runs with the tool use your user-defined input. You can also change the file name using the REPORT_FILE parameter. For example, at the Leda Tcl prompt:
leda> rule_set_parameter -rule NTL_CLK29 -parameter \
REPORT_FILE -value {MY_REPORT.tcl}
For information on Tcl procedures that you can use to control reset and PI data for runs with this rule, see the section on "Configuring Reset/PI Data for CDC Rules" in the Tcl Interface Guide.
