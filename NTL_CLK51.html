NTL_CLK51

Message: Identical gated clocks detected %s.
Description Leda flags this rule when it detects an identical gated clocks that have the same clock signal and enable signal.Arguments%s: the hierarchy name of the gate output.
Policy Design
Ruleset Clock
Language Verilog/VHDL
Type Netlist
Severity Error

Example:

The following example illustrates the rule: 

module top(Y1,Y2,Y3,D,T,EN);
  input D,T,EN;
  output Y1,Y2,Y3;

  V1 I1(.Q(Y1), .DATA(D), .CLK(T), .EN(EN));
  V2 I2(.Q(Y2), .DATA(D), .CLK(T), .EN(EN));

  DFF I3(.Q(Y3),.DATA(D),.CLK(T));

endmodule

module V1(Q,DATA,CLK,EN);
  input DATA,CLK,EN;
  output Q;

  DFF I1(.Q(Q), .DATA(DATA), .CLK(I2_Y));
  AND2 I2(.Y(I2_Y), .A(CLK), .B(EN));

endmodule


module V2(Q,DATA,CLK,EN);
  input DATA,CLK,EN;
  output Q;

  DFF I1(.Q(Q), .DATA(DATA), .CLK(I2_Y));
  AND2 I2(.Y(I2_Y), .A(CLK), .B(EN));

endmodule
Configuration:
 
rule_deselect -all
rule_select -rule NTL_CLK51
Violations:
 
    17:   AND2 I2(.Y(I2_Y), .A(CLK), .B(EN));
