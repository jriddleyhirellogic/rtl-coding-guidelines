NTL_CON04

Message: All input pins tied together

Description This rule verifies that there are no shorts between input pins in instances. Input pins may be connected via manual modification of the netlist or a non-optimized cell (can be linked to a don't touch abuse). Such problems are usually solved after reoptimization.By default, this rule checks leaf cells only (ignores hierarchical modules). If you want this rule to check all hierarchical modules, set the ONLY_APPLY_ON_LEAF_CELL parameter to 0 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON04 \
-parameter ONLY_APPLY_ON_LEAF_CELL -value {0}

By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_INPUTS to 1, to apply this check only on input ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON04 \
-parameter APPLY_ONLY_ON_INPUTS -value {1}
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

Here are examples of invalid Verilog code that illustrate the problem. In the first example, the ONLY_APPLY_ON_LEAF_CELL parameter is left at the default value of 1. In the second example, the ONLY_APPLY_ON_LEAF_CELL is set to 0: 

// ONLY_APPLY_ON_LEAF_CELL set to 1
module ntl_con04_top (Clock, Reset, Din, Dout);
input Clock, Reset, Din;
output Dout;
GTECH_FD2 I0 (.D(Clock), .CP(Clock), .CD(Clock),.Q(Dout) );  
// NTL_CON04 fires -- all input pins of GTECH_FD2 (a LEAF_CELL)
// tied together
...
endmodule

// ONLY_APPLY_ON_LEAF_CELL set to 0
module ntl_con04_top (Clock, Reset, Din, Dout);
input Clock, Reset, Din;
output Dout;
ntl_con04_sub U0 (.Clock(Din), .Reset(Din), .Din(Din), .Dout(Dout) );
// NTL_CON04 fires -- all input pins of hierarchical module
// tied together
endmodule

module ntl_con04_sub (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
...
endmodule
