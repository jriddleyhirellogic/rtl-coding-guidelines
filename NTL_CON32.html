NTL_CON32

Message: Change on net has no effect on any of the outputs.
Description Leda flags this violations when it finds a net that is not connected to any of the output signals and also forms a data loop.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

The following is an example code: 

module con32 (a, b, c, dout);
	input a, b, c;
	output dout;
	wire w1;
	wire q1;
	wire q2;   // Violation flagged on wire q1
		assign q1 = a & b;
	assign q2 = c | w1;
	assign dout = q1;a
	assign w1 = q1 & q2;
endmodule
