NTL_LAN21

Message: Netlist and libraries shall not have upper-lower case clash

Description This rule verifies that the design does not include cells with identical names (except case). Having cells with identical names (except case) but with different functionality may create problems for tools that do not differentiate between upper- and lower-case letters.
Policy DESIGN
Ruleset LANGUAGE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_lan21_top(Clock, Reset, Din, Dout1, Dout2);
input  Clock, Reset, Din;
output Dout1, Dout2;

GTECH_FD2  U0 (.D(Din), .CP(Clock), .CD(Reset), .Q(Dout1));
// OK
gtech_fd2  U1 (.D(Din), .CP(Clock), .CD(Reset), .Q(Dout2)); 
// NTL_LAN21 fires case clash
...
endmodule
