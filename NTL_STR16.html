NTL_STR16

Message: Do not use bidirectional ports in submodules of your design

Description This rule fires when Leda detects bidirectional ports in submodules of the design. Avoiding the use of bidirectional ports in submodules improves design analysis and synthesis performance at the submodule boundary.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str16_top(Ctrl, Din, Din);
input Ctrl, Din;
inout Dout;
...
ntl_str16_sub U0(.Ctrl_sub(Ctrl), .Din_sub(Din), .Dinout_sub(Dout));
endmodule

module ntl_str16_sub (Ctrl_sub, Din_sub, Dinout_sub);
input Ctrl_sub, Din_sub;
inout Dinout_sub; // NTL_STR16 fires -- inout port in submodule
wire net_int01;
...
assign Dinout_sub = Ctrl_sub ? Din_sub : 1'bz;
assign net_int01 = !Ctrl_sub ? Dinout_sub : 1'bz;
endmodule
