NTL_SET02

Message: Use only one edge of the set

Description This rule fires when Leda detects multiple edges of the set being used in the design.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_rst19_top;
input Clock, Reset;
...
wire net_11, net_21;
reg   net_12, net_22;
...
always @(posedge Clock or posedge Set)
// OK -- one edge of the Set with posedge  
begin
   if (Set)
        net_12 <= 1;
    else  net_12<= net_11;
end

always @(posedge Clock or negedge Set)
// NTL_SET02 fires -- another edge of the Set with negedge 
begin
   if (!Set)
        net_22 <= 1;
    else  net_22<= net_21;
end
