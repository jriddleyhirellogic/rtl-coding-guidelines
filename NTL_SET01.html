NTL_SET01

Message: Use only one set domain

Description This rule fires when Leda detects multiple set domains in the design. This can result in sequence errors and cause problems during set tree analysis.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_set01_top ;
...
always @(posedge Clock)
begin
     if (Set1) // OK -- one set domain
            Dout_temp <= 1;
     else Dout_temp <= Din;
end
always @(posedge Clock)
begin
      if (Set2) // NTL_SET01 fires -- two set domains
            Dout <= 1;
     else Dout <= Dout_temp;
end
endmodule
