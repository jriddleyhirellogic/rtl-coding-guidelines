NTL_CON33

Message: None of the inputs have any effect on net.
Description Leda flags this violation when it finds a net this not connected to any of the input signals and also forms a data loop.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

The following is an example code: 

module con33 (a, b,  q, dout);
	input a, b;
	output dout, q;
	wire w1;
	wire w2;
	wire w3;  // NTL_CON33 flags on wire w3
	wire w4;
	assign dout = a & b;
	assign w4 = w2 | w3;
	assign w3 = w1 & w4;
	assign q = w3;
endmodule
