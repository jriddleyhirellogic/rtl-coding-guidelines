NTL_STR55

Message: Do not use bidirectional ports for scan enable

Description This rule fires when Leda detects bidirectional ports used as scan enable signals in the design. You can help avoid design for test (DFT) failure by not using bidirectional ports for scan enable signals.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str55_top;
...
inout  Scan_en; //scan-enable port, which is a bidirectional port
out Dout;
//SDFF -- scan flip-flop cell
SDFF I0(.D(Din), .CP(Clock_sys), .CD(Reset), 
        .TI(test_in), .TE(Scan_en), .Q(Dout));  
// NTL_STR55 fires -- bidirectional port is used for scan enable
endmodule
