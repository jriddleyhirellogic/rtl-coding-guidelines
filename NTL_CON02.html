NTL_CON02

Message: Unconnected top-level output port %s1

               --- Unconnected output: %s2

               --- ...

               --- Unconnected output: %sN

Description This rule fires when Leda detects an output port that is not connected internally at the top level of the design. Output ports should be connected internally to the top-level module (primary input) to improve performance of synthesis and test insertion tools.Arguments: %s1 is the location of unconnected top-level output port.%s2 (, ..., %sN) is (are) the location(s) of port(s) connected to top- level output port in lower design hierarchy.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con02_top  (Clock, Reset, Din, Dout_uncon, Dout);
input Clock, Reset, Din; 
output Dout_uncon; //NTL_CON02 fires - unconnected top-level output port
output Dout;
reg    Dout;

always @(posedge Clock)
begin
   if (!Reset)
         Dout <= 0;
    else  Dout <= ~Din;
end
endmodule
