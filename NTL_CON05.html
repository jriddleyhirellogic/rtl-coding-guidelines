NTL_CON05

Message: Some input pins tied together %s

Description This rule verifies that there are no shorts between input pins in instances. Input pins may be connected via manual modification of the netlist or a non-optimized cell (can be linked to a don't touch abuse). Such problems are usually solved after reoptimization.By default, this rule checks leaf cells only (ignores hierarchical modules). If you want this rule to check all hierarchical modules, set the ONLY_APPLY_ON_LEAF_CELL parameter to 0 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON05 \
-parameter ONLY_APPLY_ON_LEAF_CELL -value {0}

By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_INPUTS to 1, to apply this check only on input ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON05 \
-parameter APPLY_ONLY_ON_INPUTS -value {0}

Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

Here are examples of invalid Verilog code that illustrate the problem. In the first example, the ONLY_APPLY_ON_LEAF_CELL parameter is left at the default value of 1. In the second example, the ONLY_APPLY_ON_LEAF_CELL is set to 0: 

// ONLY_APPLY_ON_LEAF_CELL = 1
module ntl_con05_top (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
GTECH_FD2 I0 (.D(Clock), .CP(Clock), .CD(Reset), .Q(Dout) );  
// NTL_CON05 fires -- some input pins of GTECH_FD2 (a LEAF_CELL)
// tied together
...
endmodule

// ONLY_APPLY_ON_LEAF_CELL = 0
module ntl_con05_top (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
ntl_con05_sub U0 (.Din(Clock), .Clock(Clock),.Reset(Reset),.Dout(Dout));
// NTL_CON05 fires -- some input pins of hierarchical module
// tied together

endmodule

module ntl_con05_sub (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
...
endmodule




  
  

    Secondary Message
    --- Input pin %s1--- Tied pin %s11...--- Tied pin %s1n...--- Input pin %sn--- Tied pin %sn1...--- Tied pin %snn...
  

  

    Argument
    


  %s is the hierarchy name of instance.




  %s1 is the hierarchy name of the first input pin that is tied.




  %s11 is the hierarchy name of the first input pin that is tied to %s1.




  %s1n is the hierarchy name of the nth input pin that is tied to %s1.




  %sn is the hierarchy name of the nth input pin that is tied.




  %sn1 is the hierarchy name of the first input pin that is tied to %sn.




  %snn is the hierarchy name of the nth input pin that is tied to %sn.
