NTL_STR78

Message: Output of latch is connected to self input

Description This rule fires when Leda detects a latch output connected to the input of itself. You can activate this rule to double check such latches.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_str78_top ();
...
wire net_01;

GTECH_LD1 I1(.D(net_01), .G(Ctrl), .Q(net_01)); 
// NTL_STR78 fires -- input is connected to output singal
...
endmodule
