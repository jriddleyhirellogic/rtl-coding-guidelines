NTL_STR66

Message: Do not instantiate big buffers

Description This rule fires when Leda detects big buffers in the design. Instantiating a set of big buffers can generate local voltage drop, which affects the performance of local standard cells and creates peak power consumption. You can configure this rule using the rule_set_parameter Tcl command and the PRE_LAYOUT_ILLEGAL_BUFFERS parameter to identify a list of illegal buffers. The default illegal buffer names are BF4T16 and BF4T32. For example:
leda> rule_set_parameter -rule NTL_STR66 \
-parameter PRE_LAYOUT_ILLEGAL_BUFFERS \
-value {BUF_PRE1, BUF_PRE2}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str66_top ;
...
// BF4T16/32 - a big fanout buffer, often used as a I/O buffer 
BF4T16 I0(.Z(net_01_bigbuf), .A(net_01));
// NTL_STR66 fires -- a big buffer
BF4T32 I1(.Z(net_02_bigbuf), .A(net_02));
// NTL_STR66 fires -- a big buffer
...
endmodule
