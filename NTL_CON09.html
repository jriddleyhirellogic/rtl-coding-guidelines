NTL_CON09

Message: All output pins are unconnected (dead gates)

Description This rule fires when Leda detects that all output pins of an instance are unconnected. An instance without any driving output pins is useless. If it does not come from a user error (connection lost that has to be regenerated) a cell without any driving pin must be removed (this is done automatically during synthesis or netlist optimization).By default, this rule checks leaf cells only (ignores hierarchical modules). If you want this rule to check all hierarchical modules, set the ONLY_APPLY_ON_LEAF_CELL parameter to 0 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON09 \
-parameter ONLY_APPLY_ON_LEAF_CELL -value {0}
If you want this rule to return redundant logic cone information, set the APPLY_LOGIC_CONE_INFO parameter to 1 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON09 \
-parameter APPLY_LOGIC_CONE_INFO -value {1}
When you set this parameter, Leda returns redundant logic cone information for the dead gate's inputs backward to primary inputs or sequentials. The redundant logic cone includes any signal track from the dead gates's driving logic cone that is only used to drive the dead gate. By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_OUTPUTS to 1, to apply this check only on output ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON09 \
-parameter APPLY_ONLY_ON_OUTPUTS -value {0}

Example

Here are examples of invalid Verilog code that illustrate the problem. In the first example, the ONLY_APPLY_ON_LEAF_CELL parameter is left at the default value of 1. In the second example, the ONLY_APPLY_ON_LEAF_CELL is set to 0: 

// ONLY_APPLY_ON_LEAF_CELL = 1
module ntl_con09_top (Clock, Reset, Din, Dout);
input Clock, Reset, Din;
output Dout;
GTECH_FD2 I0 (.D(Din), .CP(Clock), .CD(Reset), .Q( ), .QN( ) );  
// NTL_CON09 fires - all output pins (Q & QN) are unconnected
...
endmodule

// ONLY_APPLY_ON_LEAF_CELL = 0
module ntl_con09_top (Clock, Reset, Din, Dout);
input   Clock, Reset, Din;
output Dout;
ntl_con09_sub U0(.Clock(Clock),.Reset(Reset), .Din(Din), .Dout1( ), 
.Dout2( )); 
// NTL_CON09 fires - all output pins (Dout1 & Dout2) are unconnected
endmodule

module ntl_con09_sub (Clock, Reset, Din, Dout1, Dout2);
input Clock, Reset, Din;
output Dout1, Dout2;
...
endmodule
