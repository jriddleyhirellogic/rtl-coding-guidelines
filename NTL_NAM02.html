NTL_NAM02

Message: Clock ports must be assigned to internal clock signals that start with clk

Description This rule fires when Leda detects clock ports that are not assigned to internal clock signals whose names start with clk. This naming style makes the design more explicit and readable.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_nam02_top;
input Clock;  // clock signal 
...
wire  clk_name1;
//internal Clock signals whose names start with 'clk'
wire  aaa_int ; 
//internal Clock signal whose name does not start with clk
...
GTECH_FD2  U1 (.D(Din), .CP(aaa_int), .CD(Reset), .Q(Dout1));
// NTL_NAM02 fires -- clock port is not assigned to this internal clock 
// signal that starts with clk 
GTECH_BUF U0(.A(Clock), .z(clk_name1));
GTECH_FD3  U2 (.D(Din), .CP(clk_name1), .CD(Reset), .Q(Dout2));
// OK -- clk_int signal name starts with clk
endmodule
