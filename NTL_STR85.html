NTL_STR85

Message: Flip-flops likely to be merged in synthesis

Description This rule fires when Leda detects flip-flops that share the same event line and data source in the design. Such RTL descriptions of two flip-flops may be merged into one flip-flop during synthesis and thus may cause unexpected results. To improve synthesis performance, you can activate this rule and double check these structures in your design.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Warning

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str85_top ;
...
GTECH_FD2 U1(.D(Din), .CP(Clock), .CD(Reset), .Q(Dout));
GTECH_FD2 U2(.D(Din), .CP(Clock), .CD(Reset), .Q(Dout)); 
// NTL_STR85 -- U2 will be merged during synthesis optimization
...
endmodule
