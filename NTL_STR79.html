NTL_STR79

Message: Redundant logic
Description This rule fires when Leda detects redundant logic in the design. The following gates are considered to be redundant logic, since their functions could be reduced: Gates with multiple input ports, some of them connect to same net.
 XOR or NXOR gates with both inputs derived from the same signal, and there are some buffers in one of the path.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_str79_top ();
wire net_01, net_02,net_3, net_04, net_05, net_06, net 07, net_08, 
net_09;
...
GTECH_AND2 I0(.A(net_01), .B(net_01), .Z(net_02));
// NTL_STR79 fires - both connect to net_01, redundant logic
GTECH_OR3 I1(.A(net_03), .B(net_05), .c(net_03), .Z(net_04));
// NTL_STR79 fires - two pins connect to net_03, redundant logic
GTECH_BUF I2(.A(net_07), .Z(net_06));
GTECH_BUF I3(.A(net_06), .Z(net_09));
GTECH_XOR2 I4(.A(net_07), .B(net_09), .Z(net_08));
// NTL_STR79 fires - XOR gates with buffers in ore path, redundant logic

GTECH_AND2 I5(.A(net_07), .B(net_09), .Z(net_08));
// NTL_STR79 not fires -- Circuit of Noise Cancel
...
endmodule
This rule should be used only for designs that have Gate-level descriptions. It will generate meaningless violations if applied to RTL designs.
