NTL_RST11

Message: Reset signal gated with another combinatorial cell

Description This rule fires when Leda detects a combinatorial cell on a reset path. This generates a gated reset that can cause sequence problems and combinatorial cell competition.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_rst11_top;
...
wire Reset_comb;
assign Reset_comb = ~(Reset ^ ~Ctrl);
// NTL_RST11 fires -- Gated reset signal with combinatorial cell

always @(posedge Clock)
begin
   if (!Reset_comb)
        Dout <= 0;
   else Dout <= Din;
end
endmodule
