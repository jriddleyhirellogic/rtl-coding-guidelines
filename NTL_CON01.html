NTL_CON01

Message: Unconnected top-level input port %s1

               --- Unconnected input: %s2

               --- ...

               --- Unconnected input: %sN

Description This rule fires when Leda detects an input port that is not connected internally at the top level of the design. Input ports should be connected internally to the top-level module (primary input) to improve the performance of synthesis and test insertion tools.Arguments: %s1 is the hierarchy name of the primary input in top level.The source position is the line where the primary input is defined.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con01_top (Clock, Reset, Din, Din_uncon, Dout);               
input  Clock, Reset, Din; 
input  Din_uncon; // NTL_CON01 fires -- unconnected top-level input port
output Dout;
reg    Dout;

always @(posedge Clock)
begin
   if (!Reset)
         Dout <= 0;
    else  Dout <= ~Din;
end
endmodule
