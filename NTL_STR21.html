NTL_STR21

Message: The level of the design hierarchy should not exceed %d: %s

Description This rule fires when Leda detects the hierarchy level of design is more than the parameter NB_MAX_HIERARCHY_LEVEL. You can use the rule_set_parameter Tcl command and the NB_MAX_HIERARCHY_LEVEL parameter to configure the maximum number of acceptable hierarchy levels. The default is 5. For example:
leda> rule_set_parameter -rule NTL_STR21 \
-parameter NB_MAX_HIERARCHY_LEVEL -value {7}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error
