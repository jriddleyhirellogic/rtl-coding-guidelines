NTL_STR01

Message: Use only fully synchronous flip-flops

Description This rule fires when Leda detects asynchronous flip-flops (flip-flops with asynchronous sets or resets) in the design. In some cases, you want only synchronous flip-flops.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str01_top ;
...
always @(posedge Clock or negedge Reset) 
// NTL_STR01 fires -- asynchronous flip-flop in design
begin
      if(!Reset)
              Dout <= 0;
       else Dout <= Din ;
end 
endmodule
