NTL_PAD10

Message: Output port always disabled

Description This rule fires when Leda detects that output enable pin ENQ that is always disabled because it is tied to a low-power signal. You can configure this rule using the rule_set_parameter Tcl command and the SUPPLY_LOW_LIST parameter to specify the low-power signals that cannot be tied to the output port and the OUTPUT_EN_PIN parameter to specify the output enable port. Use rule NTL_PAD05 to configure the SUPPLY_LOW_LIST parameter. The default power signal name for this rule is VSS and the default output enable port name for this rule is ENQ. For example:
leda> rule_set_parameter -rule NTL_PAD05 \
-parameter SUPPLY_LOW_LIST -value {LOW_P}
leda> rule_set_parameter -rule NTL_PAD10 \
-parameter OUTPUT_EN_PIN -value {DQ}

Policy DESIGN
Ruleset PAD
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_pad10_top ;
...
supply1 VDD; //VDD is a signal in the supply_high_list (user provided)
supply0 VSS;  //VSS is a signal in the supply_low_list (user provide)

// signal named with '_pad' is an input/output of top-level
Design_core U0(Din, Dout);
...
//PAD cells: PGI_ECS277Ex - input PAD ; PGO_CDPA77Ex - output PAD;
PGI_ECS277Ex U1(.PULL(VSS), .ENABQ(VSS), .PULLQ(VDD), 
.PAD(Din_pad), .OUTI(Din));

PGO_CDPA77Ex U2(.PULL(VSS), .PP_EN(VDD), .ENQ(VSS), .PULLQ(VDD),
.PAD(Dout_pad), .DQ(Dout)); 
// NTL_PAD10 fires -- VSS is in supply_low_list (user provided). It is a 
// violation when a signal listed in the supply_low_list is connected to 
// the ENQ pin of IOLIB cells        
...
endmodule
