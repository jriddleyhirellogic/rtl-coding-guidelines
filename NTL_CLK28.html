NTL_CLK28

Message: Use only user-specified cells for clock gating

Description This rule fires when Leda detects a gated clock that is not produced by user-specified cells. Gated clocks always need an extra check to make sure they work. Using user-specified cells to produce gated clocks makes them easier to trace. You can configure this rule using the rule_set_parameter Tcl command and the CLOCK_GATING_CELLS parameter to specify the cells that are acceptable. For example:
leda> rule_set_parameter -rule NTL_CLK28 \
-parameter CLOCK_GATING_CELLS -value {USER1, 
USER2}

Policy DESIGN
Ruleset CLOCKS
Language VHDL/Verilog
Type Hardware
Severity Warning

Example

This is an example of valid Verilog code that illustrates the correct usage of user-specified cells for gated clocks: 

module ntl_clk28_top;
input Clock;  // a clock signal 
...
wire Clk_gated; // a gated clock

// USER1 - user-specified cells for clock gating (NAND/NAND/OR/...)
// USER1 I0(.Clk_in(Clock), .en(net_01), .Clk_out(Clk_gated)); 
...
endmodule
