NTL_STR45

Message: Single tristate detected

Description This rule fires when Leda detects a single tristate controlled by a signal that only controls this tristate in the design.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_str45_top ;
...
assign Dout = Ctrl  ? Din : 1'bz; 
// NTL_STR45 fires -- signal tristate detected
endmodule
