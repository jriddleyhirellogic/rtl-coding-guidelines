NTL_CON12C

Message: Undriven port: %s1

               --- Signal fanout: %s2

               --- Total range of %s3: %s4 bits (%s5: %s6)
Description An undriven port driving a cell, propagates X in the design. This rule will fire only on undriven port and not on unused port because unused port does not cause any problem and another rule NTL_LAN15 will detect such ports. This rule also detects undriven signals that have been defined in VHDL packages. If the illegal port is a part selected from an vector, a secondary message appears to report the vector's width and range information.Arguments: %s1 is the location of the undriven port.%s2 is the location of fanout of the undriven port.%s3 is the signal name of the undriven port.%s4 is the bit size of the undriven port (if it is a vector or part select of a vector).%s5 is the left bound of the vector.%s6 is the right bound of the vector.Use the parameter NTL_CON12C_APPLY_ON_UNUSED_PORT to specify if this rule should report on unused pin. You can use the rule_set_parameter Tcl command and the NTL_CON12C_APPLY_ON_UNUSED_PORT parameter to specify if you want Leda to examine for unused ports. If you don t want this rule to examine the unused port, set the value of this parameter to 0. The default value is 1. For example: 
leda> rule_set_parameter -rule NTL_CON12C \ -
parameter NTL_CON12C_APPLY_ON_UNUSED_PORT -value  
0
