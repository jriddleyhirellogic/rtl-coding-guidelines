NTL_DFT46

Message: Flip-flop scan-in pin is unconnected

Description This is not an issue if the test structure is not yet inserted. If this violation appears after scan insertion, this is probably an error that has to be fixed.
Policy DESIGN
Ruleset DFT
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_dft46_top;
...
GTECH_FD3S U0(.D(Din), .CP(Clock), .CD(Reset), 
.SD(Set), .TI( ), .TE(Scan_en), .Q(Dout));
// NTL_DFT46 fires -- scan_in pin is unconnected 
endmodule
