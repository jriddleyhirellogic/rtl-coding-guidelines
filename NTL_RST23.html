NTL_RST23

Message: Use asynchronous reset for initial reset to register

Description Leda flags this rule if the initial reset of a register is not asynchronous.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Fatal

Example

This following example illustrates the problem: 

module ntl_rst23 (Clk, Rst1, Rst2,Din);
input Clk, Rst1,Rst2, Din;
reg Rst_int1, Rst_int2, Temp1, Temp2;
always @(posedge Clk or posedge Rst1) begin
	if (!Rst1)
		Rst_int1 <= 0;
	else 
		Rst_int1 <= 1; 
end

always @(posedge Clk) begin
	if (!Rst2)
		Rst_int2 <= 0;
	else 
		Rst_int2 <= 1; / NTL_RST23 flags here
end

always @(posedge Clk) begin
	if (Rst2) 
		Temp2 <= 0;
	else
		Temp2 <= Din; // NTL_RST23 flags here
end

endmodule
