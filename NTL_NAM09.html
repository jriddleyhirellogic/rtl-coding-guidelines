NTL_NAM09

Message: Intentionally latched signals must end with _q

Description This rule fires when Leda detects intentionally latched signal names that do not end with _q. This naming style makes the design more explicit and readable.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_nam09_top(Ctrl, Din, Dout1, Dout2_q);
input  Ctrl,Din;
output Dout1;  
// NTL_NAM09 fires -- the name of intentionally latched signal
// does not end with _q
output Dout2_q; 
// OK -- The name of intentionally latched signal ends with _q
reg    Dout1;
reg    Dout2_q;

GTECH_LD1  U1 (.D(Din), .G(Ctrl), .Q(Dout1), .QN() );  
GTECH_LD1  U2 (.D(Din), .G(Ctrl), .Q(Dout2_q), .QN() );  
endmodule
