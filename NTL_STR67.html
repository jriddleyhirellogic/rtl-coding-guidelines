NTL_STR67

Message: The maximum number of flip-flops that belong to one clock domain should not exceed %d1:%s The number of flip-flops that belong to this clock domain is %d2:%s

Description This rule fires when Leda detects that the number of flip-flops in one clock domain exceeds the maximum allowed. Arguments: %d1 is the maximum number of flip-flops specified using the parameter MX_FFS_NUMBER.
 %d2 is the number of flip-flops that belong to the clock domain.
 %s is the clock domain signal.
 You can configure this rule using the rule_set_parameter Tcl command and the MX_FFS_NUMBER parameter to specify the maximum number of flip-flops based on the demands on timing constraints, clock driving strength, or your partitioning plan. The default value is 32. For example:
leda> rule_set_parameter -rule NTL_STR27 \
-parameter MX_FFS_NUMBER -value {38}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str67_top (Clock, Reset,  Din, Dout);
input  Clock, Reset;
input[32:0] Din;
output[32:0] Dout;
reg[32:0] Dout;     

// NTL_STR67 fires -- the mumber of flip-flops is 33 in one clock
// domain, but the default value is 32
always @(posedge Clock) 
begin
       if(!Reset)
               Dout<= 0;
       else  Dout<= Din;
end
endmodule
