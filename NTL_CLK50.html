NTL_CLK50

Message: Clock signal gated with a MUX.
Description Leda flags this rule when it detects a MUX in the clock path, thus a gated clock is generated in the design. Arguments%s: the hierarchy name of the module/cell.
Policy Design
Ruleset Clock
Language Verilog/VHDL
Type Netlist
Severity Error

Example:

The following example illustrates the rule: 

module top(Y1,Y2,Y3,D1,D2,D3,T,EN,T2,EN2,EN3);
 input D1,D2,D3,T,EN,T2,EN2,EN3;
 output Y1,Y2,Y3;

 DFF I1(.Q(Y1), .DATA(D1), .CLK(T));
 DFF I2(.Q(Y2), .DATA(D2), .CLK(I5_Y));
 DFF I3(.Q(Y3), .DATA(D3), .CLK(I6_Y));

 XOR2 I5(.Y(I5_Y),.A(EN2),.B(T));
 MUX2 I6(.Y(I6_Y),.D0(I5_Y), .D1(T), .S0(EN3));
endmodule
Configuration:
 
rule_deselect -all
rule_select -rule NTL_CLK50
Violations:
 
    10:  TB2MUX2XL I6(.Y(I6_Y),.D0(I5_Y), .D1(T), .S0(EN3));
         ^
