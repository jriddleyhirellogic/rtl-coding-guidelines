NTL_STR99

Message: Max area size of each module should be less than 10000

Description Consider hierarchies on a scale of 2,000 to 10,000 gates (basic blocks) to be the standard, and do not place logic gates in upper levels (Exception: CTS buffers). You can use the rule_set_parameter Tcl command to configure the MAX_AREA_SIZE and AREA_LIB parameter. The default value of MAX_AREA_SIZE is 10000 and the default value of .AREA_LIB is vcorelib.For example:
leda> rule_set_parameter -rule NTL_STR99 -parameter 
MAX_AREA_SIZE -value {20000}
leda> rule_set_parameter -rule NTL_STR99 -parameter 
AREA_LIB -value ...

If you want to change the DB library from vcorelib (default) to lsi_10k, you need to set $search_path and $link_library too.For example:
setenv search_path "<path to the lsi_10k.db>"
setenv link_library "lsi_10k.db"
leda> rule_set_parameter -rule NTL_STR99 -parameter 
AREA_LIB -value {lsi_10k}
