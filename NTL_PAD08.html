NTL_PAD08

Message: Input port always disabled

Description This rule fires when Leda detects input enable pins that are always disabled in the design because they are connected to a high-level power net. You can configure this rule using the rule_set_parameter Tcl command and the SUPPLY_HIGH_LIST parameter to specify the high-power signals that cannot be connected to input ports and the INPUT_EN_PIN parameter to specify the input enable pin. Use rule NTL_PAD06 to configure the SUPPLY_HIGH_LIST parameter. The default power signal name for this rule is VDD and the default input enable port name for this rule is ENABQ. For example:
leda> rule_set_parameter -rule NTL_PAD06 \
-parameter SUPPLY_HIGH_LIST -value {HIGH_P}
leda> rule_set_parameter -rule NTL_PAD08 \
-parameter INPUT_EN_PIN -value {DQ}

Policy DESIGN
Ruleset PAD
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_pad08_top;
...
supply1 VDD; //VDD is an signal in the supply_high_list (user provided)
supply0 VSS;  //VSS is an signal in the supply_low_list (user provide)

// signal named with '_pad' is an input/output of Top-level
Design_core U0(Ctrl, Din, Dout);
...
//PAD cells -- PGI_ECS277Ex is an input cell 
PGI_ECS277Ex  U1( .PULL(VSS), .ENABQ(VDD), .PULLQ(VDD),
.PAD(Ctrl_pad), .OUTI(Ctrl)); 
// NTL_PAD08 fires -- VDD is in supply_high_list (user provided). It is 
// a violation when a signal listed in supply_high_list is connected to 
// the ENABQ pin of IOLIB cells

PGI_ECS277Ex  U2( .PULL(VSS), .ENABQ(VSS), .PULLQ(VDD),  
.PAD(Din_pad), .OUTI(Din)); // ENABQ is OK
...
endmodule
