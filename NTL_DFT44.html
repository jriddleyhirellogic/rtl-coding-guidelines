NTL_DFT44

Message: Flip-flop set pin is unconnected

Description In most cases, flip-flops with unconnected set pins result from manual modifications of the netlist. If a flip-flop without set is really needed, it must be inferred.
Policy DESIGN
Ruleset DFT
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_dft44_top;
...
GTECH_FD3 U0(.D(Din), .CP(Clock), .CD(Reset), .SD( ), .Q(Dout));
// NTL_DFT44 fires -- set pin is unconnected
endmodule
