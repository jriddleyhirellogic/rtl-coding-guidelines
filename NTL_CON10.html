NTL_CON10

Message: Output tied to supply

Description This rule verifies that no output pins of standard cells are connected to a supply. Connecting an output pin to a supply results in a short. This has to be fixed because it increases power consumption.This rule only detects direct connections to supply (1'b0 or 1'b1) or connections to nets detected as supplies using the suplly1 or supply0 constructs. If the supply connection is implemented through a tie-off cell, this rule does not fire. You can use the rule_set_parameter Tcl command and the TIE_OFF_CELLS parameter to specify tie-off cells for this rule. This parameter is specified along with rule NTL_CON17, so you must specify the tie-off cells as follows:
leda> rule_set_parameter -rule NTL_CON17 \
-parameter TIE_OFF_CELLS -value {TIE1, TIE2}
Note that the setting for TIE_OFF_CELLS also affects the behavior of NTL_CON06, NTL_CON16, and NTL_CON17.By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_OUTPUTS to 1, to apply this check only on output ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON10 \
-parameter APPLY_ONLY_ON_OUTPUTS -value {1}
If an inout port is derived with the "PAD" attribute from a DB cell, or if the inout port is owned by an analog DB cell (with the attribute "is_analog") yet the inout port is not a digital pin (without the attribute "is_digital_pin"), such an inout port will not be taken as an output to be checked by this rule even if the parameter APPLY_ONLY_ON_OUTPUTS is set to 0. Connection of such inout ports to supply is considered to be fine.Parameter "ONLY_APPLY_ON_LEAF_CELL" allows you to configure Leda to apply this check only on leaf cells. A DB cell will be taken as leaf cell. The default value for this parameter is "1".

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con10_top (Clock, Reset, Din, Dout1, Dout2);
input  Clock, Reset, Din;
output Dout1, Dout2;

supply0 Dout1; // NTL_CON10 fires -- output tied to supply
supply1 Dout2; // NTL_CON10 fires -- output tied to supply
...
endmodule
