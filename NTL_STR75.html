NTL_STR75

Message: Different Vt cells used

Description This rule verifies that the netlist does not simultaneously include cells from the corelibv and corelibx libraries.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str75_top ();
wire net_01, net_02, net_03, net_04;
...
//ivx1v/inx1x - physical cell in different library 
ivx1v I1(.A(net_01), .Z(net_03));
// OK -- a cell in one library 
ivx1x I2(.A(net_02), .Z(net_04));
// NTL_STR75 fires -- a cell in another library with a different Vt
...
endmodule
