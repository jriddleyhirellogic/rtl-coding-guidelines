NTL_STR47

Message: Do not use latch

Description This rule fires when Leda detects latches in the design. It returns statistics on the latches found. You can activate this rule to check designs in which latches are forbidden.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str47_top ;
...
reg Dout;

always @(Ctrl or Din) // NTL_STR47 fires -- latch detected
begin 
        if (Ctrl)
           Dout <= Din;
end  
endmodule
