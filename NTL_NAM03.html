NTL_NAM03

Message: A reset port must be assigned to an internal reset signal that starts with rst

Description This rule fires when Leda detects a reset port that is not assigned to an internal reset signal whose name starts with rst. This naming style makes the design more explicit and readable.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_nam03_top;
input Reset;        // reset signal

wire  rst_name1, rst_name2 ; 
//internal reset signal whose names start with rst
wire  aaa_int ; 
//internal reset signal whose name does not start with rst

GTECH_FD2  U0 (.D(Din), .CP(Clock), .CD(rst_name1), .Q(Dout1));  
GTECH_FD2  U1 (.D(Din), .CP(Clock), .CD(aaa_int), .Q(Dout2));
// NTL_NAM03 fires -- internal reset signal whose name does not
// start with rst 
GTECH_BUF U2(.A(Reset), .Z(rst_name2));          
GTECH_FD2  U3 (.D(Din), .CP(Clock), .CD(rst_int), .Q(Dout3));  
// OK - Connect the reset port to the rst_name2 signal whose name starts
// with rst
endmodule
