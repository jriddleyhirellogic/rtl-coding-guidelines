NTL_CON12B

Message: Undriven hierarchical pin: %s1

               --- Signal fanout: %s2

               --- Total range of %s3: %s4 bits (%s5: %s6)
Description An undriven hierarchical pin driving a cell, propagates X in the design. This rule will fire only on undriven hierarchical pin and not on unused net because unused hierarchical pin does not cause any problem and another rule NTL_LAN15 will detect such hierarchical pins. This rule also detects undriven signals that have been defined in VHDL packages. If the illegal hierarchical pin is a part selected from an vector, a secondary message appears to report the vector's width and range information.Arguments: %s1 is the location of the undriven hierarchical pin.%s2 is the location of fanout of the undriven hierarchical pin.%s3 is the signal name of the undriven hierarchical pin.%s4 is the bit size of the undriven hierarchical pin (if it is a vector or part select of a vector).%s5 is the left bound of the vector.%s6 is the right bound of the vector.Use the parameter NTL_CON12B_APPLY_UNUSED_PIN to specify if this rule should report on unused pin. You can use the rule_set_parameter Tcl command and the NTL_CON12B_APPLY_UNUSED_PIN parameter to specify if you want Leda to examine for unused ports. If you don t want this rule to examine the unused pin, set the value of this parameter to 0. The default value is 1. For example: 
leda> rule_set_parameter -rule NTL_CON12B \ -
parameter NTL_CON12B_APPLY_UNUSED_PIN -value  0
