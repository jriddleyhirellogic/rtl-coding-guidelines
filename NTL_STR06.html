NTL_STR06

Message: Top-level output should be registered

Description This rule fires when Leda detects an output of the top-level module that is not registered. When a signal is derived from a flip-flop, it is treated as registered. But it will not fire if the output is connected to a flip-flop by renaming, or a buffer, or an inverter. Registering all outputs of top-level modules facilitates a synchronous coding style that improves simulation performance.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code. 

module ntl_str06_top (Dout1, Dout2, Dout3, Dout4, Reset, Din, Clock;
output Dout1, Dout2, Dout3, Dout4;
...
assign Dout1 = Reset & Din;  // NTL_STR06 fires -- output is not 
				 // registered

always @(posedge Clock)
           Dout2 <= Din;           // OK -- output is registered
assign Dout3 = ~Dout2;     //OK -- output is connected to a flip-flop by 
                           //an inverter
assign Dout4 = Dout2;      //OK -- output is connected to a flip-flop by 
                           //renaming 
endmodule
