NTL_CON16

Message: Nets or cell pins should not be tied to logic 0 / logic 1

Description This rule verifies that no nets or cell pins are connected to logic 0 or logic 1. Connections to supplies must be done using dedicated tie-off cells.This rule only detects direct connections to supply (1'b0 or 1'b1) or connections to nets detect as supplies using the suplly1 or supply0 constructs. If the supply connection is implemented through a tie-off cell, this rule does not fire. You can use the rule_set_parameter Tcl command and the TIE_OFF_CELLS parameter to specify tie-off cells for this rule. This parameter is specified along with rule NTL_CON17, so you must specify the tie-off cells as follows:
leda> rule_set_parameter -rule NTL_STR100 \
-parameter MAX_AREA_SIZE -value {20000}
leda> rule_set_parameter -rule NTL_CON17 \
-parameter TIE_OFF_CELLS -value {TIE1, TIE2}
Note that the setting for TIE_OFF_CELLS also affects the behavior of NTL_CON06, NTL_CON10, and NTL_CON17.
Policy DESIGN
Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_con16_top (Clock, Din, Dout  );
input  Clock, Din; 
output Dout;
wire D_int1, D_int2;

assign D_int1 = 1'b0; // NTL_CON 16 fires -- net tied to logic 0
assign D_int2 = 1'b1; // NTL_CON 16 fires -- net tied to logic 1
GTECH_FD1 U0 (
            .D(1'b1), // NTL_CON 16 fires -- net tied to logic 1
            .CP(Clock), 
            .Q(Dout));
endmodule
