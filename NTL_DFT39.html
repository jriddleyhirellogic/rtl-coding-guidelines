NTL_DFT39

Message: Flip-flop without scan-in detected

Description Flip-flops without scan-in pins cannot be inserted in the scan path.
Policy DESIGN
Ruleset DFT
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_dft39_top;
...
// flip-flop - DFF
DFF U1(.D(Din), .CP(Clock), .Q(net_01)); 
// NTL_DFT39 fires -- without scan_in

// Scan DFF -- SDFF
SDFF U2(.D(net_02), .CP(Clock), .CD(Reset),
.TI(net_01), .TE(Scan_en), .Q(Dout)); // OK -- with scan_in
endmodule
