NTL_CON08

Message: Floating output pin

Description This rule verifies that no output pins of instances are left unconnected. In some cases (for sequential cells) you don't need to have all output pins driving. If all output pins are unconnected, this is a design error, and another rule related to all output pin connections fires (see NTL_CON09).By default, this rule checks leaf cells only (ignores hierarchical modules). If you want this rule to check all hierarchical modules, set the ONLY_APPLY_ON_LEAF_CELL parameter to 0 (the default value is 1). For example:
leda> rule_set_parameter -rule NTL_CON08 \
-parameter ONLY_APPLY_ON_LEAF_CELL -value {0}
By default, this check is applied on the inout ports. You can set parameter APPLY_ONLY_ON_OUTPUTS to 1, to apply this check only on output ports (the default value is 0). For example:
leda> rule_set_parameter -rule NTL_CON08 \
-parameter APPLY_ONLY_ON_OUTPUTS -value {1}
If an inout port is derived with the "PAD" attribute from a DB cell, or if the inout port is owned by an analog DB cell (with the attribute "is_analog") yet the inout port is not a digital pin (without the attribute "is_digital_pin"), such an inout port will not be taken as an output to be checked by this rule even if the parameter APPLY_ONLY_ON_OUTPUTS is set to 0. Connection of such inout ports to supply is considered to be fine.

Ruleset CONNECTIVITY
Language VHDL/Verilog
Type Hardware

Example

Here are examples of invalid Verilog code that illustrate the problem. In the first example, the ONLY_APPLY_ON_LEAF_CELL parameter is left at the default value of 1. In the second example, the ONLY_APPLY_ON_LEAF_CELL is set to 0: 

// ONLY_APPLY_ON_LEAF_CELL = 1
module ntl_con08_top (Clock, Reset, Din, Dout);
input Clock, Reset, Din;
output Dout;
GTECH_FD2 I0 (.D(Din), .CP(Clock), .CD(Reset), .Q(Dout), .QN( ) );  
// NTL_CON08 fires - QN is a floating output pin
...
endmodule

// ONLY_APPLY_ON_LEAF_CELL = 0
module ntl_con08_top (Clock, Reset, Din, Dout);
input Clock, Reset, Din;
output Dout;
ntl_con08_sub U0(.Clock(Clock),.Reset(Reset), .Din(Din),.Dout1(Dout), 
.Dout2( )); 
// NTL_CON08 fires - Dout2 is a floating output pin
endmodule

module ntl_con08_sub (Clock, Reset, Din, Dout1, Dout2);
input Clock, Reset, Din;
output Dout1, Dout2;
...
endmodule
