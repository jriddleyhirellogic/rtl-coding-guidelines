NTL_NAM16

Message: Active low signals must end with "_X, _N"

Description This rule fires when Leda detects active-low signal names that do not end with _X or _N. This naming style makes the design more explicit and readable.
Policy DESIGN
Ruleset NAMING
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module test(Clock, rst_X, rst, Din_1, Din_2, Dout_1, Dout_2);
input Clock, rst_X, rst, Din_1, Din_2;
output Dout_1, Dout_2;
reg  Dout_1, Dout_2;

always @(posedge Clock or negedge rst) begin
  if (!rst)          // NTL_NAM16 fires -- name does not end with _X, _N
     Dout_1 <= 1'b0;
  else
     Dout_1 <= Din_1;
end
  
always @(posedge Clock or negedge rst_X) begin
  if (!rst_X)            // OK -- Active low signal name ends with _X
     Dout_2 <= 1'b0;
  else
     Dout_2 <= Din_2;
end

endmodule
