NTL_DFT48

Message: Flip-flop scan-enable pin not connected to scan-enable signal

Description For the chip to behave properly in test mode, the scan-enable pin must be connected to a scan-enable signal. Violations of this rule may occur if the synthesis tool is not properly constrained and uses the scan capability of the flip-flop for functional mode.
Policy DESIGN
Ruleset DFT
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_dft48_top(Clock, Scan_in, Scan_en, Din, Dout);
input  Clock, Scan_in, Scan_en,  Din;
output Dout;
wire Dout_int;
wire int_signal; 
// NTL_DFT48 fires -- interior signal, not scan_enable signal
...
GTECH_FD1S U0(.D(Din), .CP(Clock), .TI(Scan_in), .TE(Scan_en), 
.Q(Dout_int)); 
GTECH_FD1S U1(.D(Dout_int), .CP(Clock), .TI(Dout_int), .TE(int_signal), 
.Q(Dout)); 
endmodule
