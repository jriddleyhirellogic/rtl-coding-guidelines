NTL_STR65

Message: The number of buffers/inverters should not exceed the user specified percentage of total cell count: %s1

Description This rule fires when Leda detects that the number of buffers/inverters in the design exceeds the user specified percentage of total cell count. This information is important because it identifies bufferization that may occur during synthesis. In some cases, the number of buffers/inverters in the design is taken as an index of timing/power estimate. Arguments: %s1 is the top instance name
 Source Position: The position is the line in which the top instance is defined.
 You can configure this rule using the rule_set_parameter Tcl command and the following parameters:
    • BUFFERS_PERCENT to specify the acceptable buffer percentage. The default value is 5.
    • INVERTERS_PERCENT to specify the acceptable inverter percentage. The default value is 5.
    • BUFS_INVS_PERCENT to specify the acceptable buffer and inverter total percentage. The default value is 10.
For example:
leda> rule_set_parameter -rule NTL_STR65 \
-parameter BUFFERS_PERCENT -value {7}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

This rule should be used only for designs that have Gate-level descriptions. It will generate meaningless violations if applied to RTL designs.
 Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str65_top (Reset, Din, Dout);
input   Reset, Din;
output  Dout;
wire Din_int, Reset_inv;
buf I1(Din_int, Din);
//NTL_STR65, number of buffers/inverters exceeds cell count by 5 percent
not I2(Reset_inv, Reset);
xnor I3(Dout, Din_int, Reset_inv);
endmodule
