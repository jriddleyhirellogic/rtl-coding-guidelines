NTL_RST09

Message: Reset signal gated with an OR gate

Description This rule fires when Leda detects an OR gate on a reset path. This generates a gated reset that can cause sequence problems and logic gate competition.
Policy DESIGN
Ruleset RESETS
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_rst09_top ;
...
wire Reset_OR;

assign Reset_OR = Reset | Ctrl;
// NTL_RST09 fires -- OR gated reset signal

always @(posedge Clock)
begin
   if (!Reset_OR)
        Dout <= 0;
   else Dout <= Din;
end
endmodule
