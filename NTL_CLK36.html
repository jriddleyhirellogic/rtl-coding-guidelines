NTL_CLK36

Message: Do not use cells that have sdf_cond attribute in clock line.

Description This rule detects clock origins that are derived from a cell with an sdf_cond attribute in the design. Such clock origins are dangerous in some cases when the sdf condition matches because this may cause the clock signal to be unstable.
Policy DESIGN
Ruleset CLOCKS
Language VHDL/Verilog
Type Hardware
Severity Error
