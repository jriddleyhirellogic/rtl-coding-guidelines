NTL_RST24

Message: Source and Destination flip-flops use different asynchronous resets.

Source flip-flop: %S

Description LEDA flags the rule when the source flip-flop and destination flip-flop use different asynchronous reset. When one flip-flop drive the data input of other flip-flops passing any combinational logic, then the driver flip-flop is called the source flip-flop, and the driven flip-flop as destination flip-flop.Note: When there are only buffers, or inverters between the path of the source and destination flip-flop reset, both the resets are considered to be the same. The following are the parameters for this rule:
    • IGNORE_SRC_RST: LEDA does not report the violation when the source reset is any of the one specified by the parameter.
    • IGNORE_SRC_FF: LEDA does not report the violation when the source flip-flop is any of the one specified by the parameter.

    • IGNORE_DES_RES: LEDA does not report the violation when the destination reset is any of the one specified by the parameter.
    • IGNORE_DES_FF: LEDA does not report the violation when the destination flip-flop is any of the one specified by the parameter.
    • CHECK_FILTER: LEDA does not report the violation when there is a path from the source flip-flop reset pin to the data pin of the destination flip-flop.
Policy DESIGN
Ruleset Reset
Language VHDL/Verilog
Type Hardware
Severity Warning

Example

This is an example of invalid Verilog code that illustrates the problem: 

module top;
wire clk,rst1,rst2,rst3,rst4,rst5,data1,data2;
reg [1:0] dout5;
reg [2:0] dout;

always @(posedge clk or posedge rst1)
  if(rst1)
    dout[0] <= 0;
  else
    dout[0] <= dout5[0];

always @(posedge clk or posedge rst2)
  if(rst2)
    dout[1] <=0;
  else
    dout[1] <= dout5[1];

always @(posedge clk or posedge rst3)
  if(rst3)
    dout[2] <= 0;
  else
    dout[2] <= dout5[0];

always @(posedge clk or posedge rst4)
  if(rst4)
    dout5[0] <= 0;
  else
    dout5[0] <= data1;

always @(posedge clk or posedge rst3)
  if(rst3)
    dout5[1] <= 0;
  else
    dout5[1] <= data2;

endmodule

Example

The following example illustrates the valid Verilog code: 

module top;
wire clk,rst1,rst2,data1,data2;
reg [1:0] dout5;
reg [2:0] dout;

always @(posedge clk or posedge rst1)
  if(rst1)
    dout[0] <= 0;
  else
    dout[0] <= dout5[0];

always @(posedge clk or posedge rst2)
  if(rst2)
    dout[1] <=0;
  else
    dout[1] <= dout5[1];

always @(posedge clk or posedge rst1)
  if(rst3)
    dout[2] <= 0;
  else
    dout[2] <= dout5[0];

always @(posedge clk or posedge rst1)
  if(rst4)
    dout5[0] <= 0;
  else
    dout5[0] <= data1;


always @(posedge clk or posedge rst2)
  if(rst3)
    dout5[1] <= 0;
  else
    dout5[1] <= data2;
endmodule
