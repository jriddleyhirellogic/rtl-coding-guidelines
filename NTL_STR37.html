NTL_STR37

Message: Avoid combinatorial logic on the control signal of a tristate driver

Description This rule fires when Leda detects combinatorial logic on the control signal of a tristate driver. Removing the combinatorial logic on the control signal of a tristate driver can help avoid data competition.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code, followed by a circuit diagram that illustrates the problem: 

module ntl_str37_top;
output Dout; 
...
assign Ctrl_int = Reset? ~Ctrl : 0; 
// NTL_STR37 fires -- combinatorial logic on the control signal
assign Dout = Ctrl_int? Din : 1'bz;
endmodule
