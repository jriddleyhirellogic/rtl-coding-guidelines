NTL_STR88

Message: The number of ports in modules

Description This rule calculates and reports the number of ports in all modules of the design.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Note

Example

Here is an example that shows a gate-level design and the report that Leda generates for it when this rule is on: 

module ntl_str88_top (Clk, Din, Dout);
input   Clk, Din;
output Dout;
reg D_temp1, D_temp2;

GTECH_FD1    I0 (.D(Din), .CP(Clk), .Q(D_temp1));
GTECH_FD1    I1 (.D(D_temp1), .CP(Clk), .Q(D_temp2));
GTECH_AND2 I2 (.A(D_temp1), .B(D_temp2), .Z(Dout));
endmodule

// Leda reports:
//ntl_str88_top: 3  ntl_str88_top ...
