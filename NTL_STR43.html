NTL_STR43

Message: Use template for inferred tristate buffer

Description This rule fires when Leda detects tristate buffers in the design that are identified based on a user-specified prefix. You can use the rule_set_parameter Tcl command and the TRISTATE_TEMPLATE_NAME parameter to specify the prefix that Leda uses to check these buffers. The default value is TRI_. For example:
leda> rule_set_parameter -rule NTL_STR43 \
-parameter TRISTATE_TEMPLATE_NAME -value {HIMP_}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str43_top ;
wire Ctrl, Din, Dout;
BAD_buf I1(Ctrl, Din, Dout);

// NTL_STR43 fires -- template for tristate buf with the name of TRI_ 
endmodule

module BAD_buf (Ctrl, Din, Dout);
  input Ctrl, Din;
  output Dout;

  assign Dout = Ctrl ? Din : 1'bz;

endmodule
