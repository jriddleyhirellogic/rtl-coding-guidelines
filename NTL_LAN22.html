NTL_LAN22

Message: Do not use escaped names

Description This rule reports all uses of escaped characters in the netlist. Escaped characters are not handled correctly by all place-and-route tools. It is a good idea to generate a clean netlist without escaped characters before starting place-and-route.
Policy DESIGN
Ruleset LANGUAGE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_lan22_top;
...
wire   \$escap_cha1 ;  
// NTL_LAN22 fires -- '\$escap_cha1' is a escaped name
wire   \*escap_cha2 ; 
// NTL_LAN22 fires -- '\*escap_cha2' is a escaped name

assign \$escap_cha1 = Ctrl &  Din ;
assign  Dout1 = ~ \$escap_cha1 ;

nand I0(\*escap_cha2 , Ctrl, Din);
not   I1(Dout2, \*escap_cha2 );
...
endmodule
