NTL_STR48

Message: Latches shall be instantiated using the VLSI generic latch components

Description This rule fires when Leda detects latches in the design that are not instantiated with VLSI generic latch components. It returns statistics on the latches found.You can use the rule_set_parameter Tcl command and the GENERIC_LATCHES parameter to specify the name of the VLSI generic latch component that Leda checks. The default value is LD1_GENERIC, LD2_GENERIC. For example:
leda> rule_set_parameter -rule NTL_STR48 \
-parameter GENERIC_LATCHES -value {GEN_LAT1}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of valid Verilog code that illustrates the correct approach: 

module ntl_str48_top ;
...
LD1_GENERIC U1(.D(Din1), .G(Ctrl), .Q(Dout1)); 
// OK -- A latch named LD1_GENERIC is a VSLI generic
// latch component (default)
LD2_GENERIC U2(.D(Din2), .G(Ctrl), .Q(Dout2)); 
// OK -- A latch named LD2_GENERIC is a VSLI generic
// latch component (default)
// a latch cell -- LATCH_logic
LATCH_logic U3 (.D(Din3), .G(Ctrl2), .Q(Dout3));
// NTL_STR48 fires -- this latch is not the VLSI generic latch 
// component
endmodule
