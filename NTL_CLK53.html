NTL_CLK53

Message: Detected the cell which contains multiple gated clocks.
Description Leda flags this rule when it detects the cell which contains multiple gated clocks.
Arguments%s: the hierarchy name of the module/cell.
Policy Design
Ruleset Clock
Language Verilog/VHDL
Type Netlist
Severity Error

Example:

The following example illustrates the rule: 

module top(Y1,Y2,Y3,D1,D2,D3,T,EN,T2,EN2,EN3);
 input D1,D2,D3,T,EN,T2,EN2,EN3;
 output Y1,Y2,Y3;

 DFF I1(.Q(Y1), .DATA(D1), .CLK(I4_Y));
 DFF I2(.Q(Y2), .DATA(D2), .CLK(T));
 DFF I3(.Q(Y3), .DATA(D3), .CLK(T2));

 ON21 I4(.YB(I4_Y),.A0(T2), .A1(T), .B(EN));
endmodule
Configuration:
 
rule_deselect -all
rule_select -rule NTL_CLK53
