NTL_STR26

Message: No INOUTs at any top level block; although acceptable, they consume a lot of resources in the box

Description This rule fires when Leda detects INOUT ports in a top-level block. An "io" cell takes more area than common "in" or "out" cell, since it contains a control port that is used to switch io port to in or out status and thus more resource is consumed at chip area.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str26_top;
...
inout Dout;    // NTL_STR26 fires -- INOUT at top level block
wire net_01;
...
assign Dout   = Ctrl? 1'bz : Din;
assign net_01 = Ctrl? Dout : 1'bz;
endmodule
