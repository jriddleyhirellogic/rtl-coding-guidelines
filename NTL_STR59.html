NTL_STR59

Message: Inout signal connect to register clock

Description This rule fires when Leda detects inout signals that are used to clock registers (flip-flops or latches). To keep registers controllable, avoid using inout signals to clock them.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str59_top;
...
inout  Dout;
...
always @(posedge Dout)
// NTL_STR59 fires -- inout signal connect to register clock
begin
      if(Reset)
           Dout_temp <= 0;
       else  Dout_temp <= Din;
end
endmodule
