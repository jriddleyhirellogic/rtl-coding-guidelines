NTL_LAN24

Message: Do not distinguish names by using upper or lower-case English letters in the same module

Description This rule fires when Leda detects both upper- and lower-case letters used in the same module.
Policy DESIGN
Ruleset LANGUAGE
Language VHDL/Verilog
Type Hardware
Severity Warning

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_lan24_top;
...
wire d1, d2, D1;  

assign D1 = d1 & d2; 
// NTL_LAN24 fires -- D1 and d1 detected as rule violation
endmodule
