NTL_CON13C

Message: Non-driving port: %s1

                --- Total range of %s2: %s3 bits (%s4: %s5) 




  
  

    Description
    Non-driving ports are useless and must be removed. This rule will fire on non-driving port, but will not fire on unused port, because unused ports do not cause any problem and another rule NTL_LAN15 will detect such pins. If the illegal port is a part selected from a vector, a secondary message appears to report the vector's width and range information.Arguments: %s1 is the non-driving port source position which is the line where the non-driving pin is defined;%s2 is the signal name of the non-driving port;%s3 is the bit size of the no-driving port (if it is a vector or part select of a vector);%s4 is the left bound of the vector;%s5 is the right bound of the vector;You can use the rule_set_parameter Tcl command and the NTL_CON13C_APPLY_ON_UNUSED_PORT parameter to specify if you want Leda to examine for unused port. If you don't want this rule to examine the unused port, set the value of this parameter to 0. The default value is 1. For example:
leda> rule_set_parameter -rule NTL_CON13C \ -
parameter NTL_CON13C_APPLY_ON_UNUSED_PORT -value  
0


You can use the rule_set_parameter Tcl command and the NTL_CON13C_IGNORE_SUPPLY_ASSIGNMENT parameter to specify if you want Leda to ignore port that has been assigned to supply. If you want this rule to ignore port that has been assigned to supply, set the value of this parameter to 1. The default value is 0. For example:
leda> rule_set_parameter -rule NTL_CON13C \ -
parameter NTL_CON13C_IGNORE_SUPPLY_ASSIGNMENT -
value 1
