NTL_STR68

Message: Don't use that cell

Description This rule fires when Leda detects gates instantiated from an invalid cell. You can use the rule_set_parameter Tcl command and the ILLEGAL_CELL parameter to specify a list of cells that are not valid for your design. The default illegal cell names are BF2TB and BF2T16. For example:
leda> rule_set_parameter -rule NTL_STR68 \
-parameter ILLEGAL_CELL -value {BF2T8, BF2T16}

Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str68_top;
...
// BF2T8/16 - physical cells in library
BF2T8  I1(.Z(net_01_bigbuf), .A(net_01));
// NTL_STR68 fires -- don't use this cell (default)
BF2T16 I2(.Z(net_02_bigbuf), .A(net_02));
// NTL_STR68 fires -- don't use this cell (default)
...
endmodule
