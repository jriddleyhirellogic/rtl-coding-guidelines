NTL_STR56

Message: Do not use sequential registers with both asynchronous set and asynchronous reset

Description Leda flags this rule when it detects sequential registers (flip-flops or latches) with both asynchronous sets and resets in the design. Such registers can result in data contradictions and failures.
You can use the rule_set_parameter Tcl command and parameter "ONLY_APPLY_ON_FF" to apply this check only on flip-flop by setting this parameter to 1 (The default value is 0). For example:
leda> rule_set_parameter -rule NTL_STR56 -parameter ONLY_APPLY_ON_FF -value 1
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_str56_top (Clock, Reset, Set, Din, Dout);
input  Clock, Reset, Set, Din;
output Dout;
reg Dout;
always @(posedge Clock or posedge Reset or posedge Set)  
begin
    if(Reset)//NTL_SDT56, flip-flop with both asynchronous set and reset
           Dout <= 0;
     else if (Set)
           Dout <= 1;
     else  Dout <= Din;
end
endmodule
