NTL_PAD07

Message: Push pull always disabled

Description This rule fires when Leda detects push pull pins that are disabled in the design. When a push pull enable pin is connected to a low-level power net, it is treated as disabled. You can configure this rule using the rule_set_parameter Tcl command and the SUPPLY_LOW_LIST parameter to specify the low-power signals that cannot be connected to the push pull pin and the PUSH_PULL_EN_PIN parameter to specify the push pull signal. Use rule NTL_PAD05 to configure the SUPPLY_LOW_LIST parameter. The default power signal name for this rule is VSS and the default push pull pin name is PP_EN. For example:
leda> rule_set_parameter -rule NTL_PAD05 \
-parameter SUPPLY_LOW_LIST -value {LOW_P}
leda> rule_set_parameter -rule NTL_PAD07 \
-parameter PUSH_PULL_EN_PIN -value {DQ}

Policy DESIGN
Ruleset PAD
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of invalid Verilog code that illustrates the problem: 

module ntl_pad07_top;
...
supply1 VDD; //VDD is an signal in the supply_high_list(user provided)
supply0 VSS; /VSS is an signal in the supply_low_list (user provide)

// signal named with '_pad' is an input/output of top-level
Design_core U0(Ctrl, Din, Dout1, Dout2);

//PAD cells - PGO_CDPA77Ex is a output cell with push pull pin (PP-EN)
PGO_CDPA77Ex  U1( .PULL(VSS), .PP_EN(VSS), .ENQ(VDD), .PULLQ(VDD),
.PAD(Dout1_pad), .DQ(Dout1)); 
// VNTL_PAD07 fires -- VSS is in supply_low_list (user provided). It is 
// a violation when a signal listed in supply_low_list is connected to 
// the PP-EN pin of IOLIB cells

PGO_CDPA77Ex  U2( .PULL(VSS), .PP_EN(VDD), .ENQ(VDD), .PULLQ(VDD), 
.PAD(Dout2_pad), .DQ(Dout2));  // PP-EN is OK 
...
endmodule
