NTL_STR77A

Message: Prohibited cell found %s

Description This rule fires when Leda detects prohibited cells in the design. Cells that are not included in the list of allowed cells are considered as prohibited cells. You can use the rule_set_parameter Tcl command and the ALLOWED_CELLS parameter to configure the list of allowed cells. The default value is an empty cell. For example:
leda> rule_set_parameter -rule NTL_STR77A \
-parameter ALLOWED_CELLS -value {CELL1, CELL2 
CELL3}
Wild cards can also be used to specify the parameter values. For example, -value {[A-I]CELL? CELL* *CELL}By default, this rule will report only once even if the prohibited cell is instantiated multiple times. To enable reporting violation for each prohibited cell instantiation, the following parameter should be set as follows:
leda> rule_set_parameter -rule NTL_STR77A \
-parameter MSG_ON_EACH_INSTANCE -value {1}
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Error

Example

This is an example of Verilog code that illustrates the problem: 

module top;
        sub1  sub1;
        sub2  sub2;
        AN2   an2  (.A(), .B(), .Z());
        AN2I  an21 (.A(), .B(), .Z());
        OR2   or2  (.A(), .B(), .Z());
        OR2I  or2i (.A(), .B(), .Z());
        IV    iv   (.A(),       .Z());
        IVI   ivi  (.A(),       .Z());
        IVP   ivp  (.A(),       .Z());
        IVA   iva  (.A(),       .Z());
        IVAP  ivap (.A(),       .Z());
        IVDA  ivda (.A(), .Y(), .Z());
        IVDAP ivdap(.A(), .Y(), .Z());
endmodule

module sub1;
        sub3 sub3;
endmodule

module sub3;
endmodule

module sub2;
endmodule
