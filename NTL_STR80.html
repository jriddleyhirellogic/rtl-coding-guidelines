NTL_STR80

Message: The total cell area

Description This rule calculates and returns the total cell area in the design.
Policy DESIGN
Ruleset STRUCTURE
Language VHDL/Verilog
Type Hardware
Severity Note

Example

This is an example of valid Verilog code that illustrates this reporting feature: 

module ntl_str80_top;
wire net_01, net_02;
//invx05 - a cell in  the physical library , area is 6.0516 (unit)
ivx05 I0(.A(net_01), .Z(net_02));  
// NTL_STR80 reports -- total cell area is 6.051600,
// the same as the area in physical library
endmodule
